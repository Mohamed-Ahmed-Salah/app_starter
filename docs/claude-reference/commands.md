# Commands

## Running

Single entrypoint (`lib/main.dart`); the flavor comes from Flutter's `--flavor`, which
`init()` reads via the built-in `appFlavor` constant.

```bash
flutter run --flavor dev
flutter run --flavor prod
```

Omitting `--flavor` makes `F.appFlavor` throw during `init()` — the `firstWhere` in
`injection_container.dart` finds no match. Always pass one.

The native side of each flavor (Android product flavors, iOS schemes, launcher icons) is
generated by `flutter_flavorizr` from the `flavorizr:` block in `pubspec.yaml`. Until it
has been run, `--flavor` has nothing to select. Replace every `CHANGE_ME` (app name,
application/bundle ids, 1024x1024 icons under `assets/logo/`), then:

```bash
dart run flutter_flavorizr
```

Re-run after any change to that block; it overwrites the generated native files.

## Codegen

One command covers both Freezed (cubit states) and injectable (DI registration):

```bash
dart run build_runner build
```

Run it after changing a **state** class, or after adding, removing, re-annotating, or
changing the constructor of any `@injectable` / `@lazySingleton` class. Not needed for
method-body edits. (`--delete-conflicting-outputs` is gone in this build_runner; outputs
are overwritten by default.)

Localization, after editing `lib/l10n/*.arb`:

```bash
flutter gen-l10n
```

`generate: true` is set in `pubspec.yaml`, so a normal build also regenerates. Unresolved
keys are written to `untranslated.txt`.

## Analyzing

```bash
flutter analyze lib/
```

The starter analyzes clean apart from a handful of infos inherited with `core/`. Assume
any info you didn't cause is baseline; confirm with `git stash` if it matters.

Filter to what matters:

```bash
flutter analyze lib/ 2>&1 | grep -E "^\s*error"        # must be empty
flutter analyze lib/ 2>&1 | grep "path/to/file.dart"   # your files only
```

Treat **zero errors** as the bar. Don't try to clear the baseline warnings as a side effect
of an unrelated change.

## Testing

```bash
flutter test
```

`test/` is sparse — check it exists for the area before claiming coverage.
